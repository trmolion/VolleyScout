<h1 align="center">VolleyScout</h1>

<p align="center">Скаутинг волейбольного матча по видео</p>

## Зачем

VolleyScout собирает статистику игроков по записи матча. Во время просмотра видео действия игроков отмечаются короткими командами: кто подал, принял, атаковал и с каким результатом. Приложение считает статистику по каждому игроку и сохраняет её в таблицу Excel.

Плеер, ввод и таблица находятся в одном окне.

## Установка

Требования:

- Windows 10 или новее, 64 бита
- 210 МБ на диске
- Qt и FFmpeg входят в комплект, дополнительные компоненты не нужны

Порядок:

1. Загрузка `VolleyScout-<версия>-win64.exe` со страницы [релизов](https://github.com/trmolion/VolleyScout/releases).
2. Запуск инсталлятора. Он не подписан, поэтому SmartScreen показывает предупреждение: «Подробнее» → «Выполнить в любом случае».
3. Запуск приложения с ярлыка на рабочем столе или из меню «Пуск».

Вариант без установки — архив `VolleyScout-<версия>-win64.zip` с той же страницы: распаковывается в любую папку, запускается файлом `VolleyScout.exe`.

Под Linux приложение собирается из исходников: [docs/BUILDING.md](docs/BUILDING.md).

## Как пользоваться

В приложении два режима, они переключаются вверху окна.

### Формирование

Запись действий по видео.

1. Видео матча открывается кнопкой «Открыть видео…».
2. Лишнее в начале и в конце отрезается кнопками «Начало здесь» и «Конец здесь».
3. Дата и названия команд задаются в строке под видео.
4. Действие записывается командой: выбор партии (s1–s5), ввод команды, Enter. Запись получает таймкод текущего момента.
5. Результат сохраняется кнопками «Сформировать таблицу» и «Сформировать скауты».

Команда состоит из номера игрока, действия и оценки. Например, `13s+` — игрок 13, подача, хорошо.

| Код | Действие |
|---|---|
| `s` | подача |
| `r` | приём |
| `a` | атака |
| `b` | блок |
| `d` | защита |

| Код | Оценка |
|---|---|
| `#` | отлично |
| `+` | хорошо |
| `!` | средне (только приём и защита) |
| `-` | плохо |
| `=` | ошибка |

Управление:

- Пробел — воспроизведение и пауза. Работает и из поля ввода команды.
- Перемотка на 5 секунд назад и вперёд, скорость от 0.25× до 2×.
- Щелчок по времени записи в истории переводит видео к этому моменту.
- Двойной щелчок по номеру партии меняет его, крестик удаляет запись.

Что сохраняется:

- «Сформировать скауты» — архив `.zip`, в нём по одному `.txt` на партию, по одной команде в строке.
- «Сформировать таблицу» — книга `.xlsx` и тот же архив рядом с ней. В книге лист «Матч» со всеми партиями и по листу на каждую партию.

Для каждого игрока в таблице указано число действий каждого типа, а также количество и доля каждой оценки. Записи за пределами обрезанного видео в выгрузку не попадают.

### Таблица

Просмотр готовых скаутов.

1. Скаут открывается кнопкой «Открыть скаут…»: `.txt` одной партии или `.zip` всего матча.
2. Партии переключаются внизу окна.
3. ФИО игроков вписываются на вкладке «Команда» и появляются в таблице вместо «Игрок N».
4. Щелчок по игроку в правой панели подсвечивает его строку в таблице.
5. Кнопка «Экспорт .xlsx» сохраняет таблицу открытой партии.

После «Сформировать таблицу» приложение само открывает результат в этом режиме.
